# AATKD

Official implementation of **"Attention-Based Adaptive Temperature Knowledge Distillation"**.

## Introduction

This repository provides the official implementation of **Attention-Based Adaptive Temperature Knowledge Distillation (AATKD)**.

AATKD introduces an adaptive temperature learning mechanism for knowledge distillation, enabling the student network to learn sample-wise temperature preferences from multiple candidate temperatures.
